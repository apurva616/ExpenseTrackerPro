# ExpenseTracker Pro

A modern Expense Tracker web application built using Flask, SQLite, HTML, CSS and JavaScript.

## Features

- User Registration & Login
- Secure Password Hashing
- Session Authentication
- Dashboard with Expense Summary
- Add, Edit & Delete Expenses
- Expense Search & Filtering
- Analytics Charts
- Dark Mode
- Responsive Design

## Technologies

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Chart.js

## Installation

```bash
pip install -r requirements.txt
python app.py
```

Open your browser:

```
http://127.0.0.1:5000
```

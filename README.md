# 💰 ExpenseTracker Pro

A modern full-stack personal finance management web application built using **Flask, SQLite, HTML, CSS, JavaScript, and Chart.js**.

## 🌐 Live Demo

**https://expensetrackerpro-3vh9.onrender.com**

## ✨ Features

* 🔐 User Registration & Login
* 🔒 Secure Password Hashing
* 💰 Add, Edit & Delete Expenses
* 📂 Category Management
* 🔍 Search & Filter Expenses
* 📊 Interactive Analytics Dashboard
* 🎯 Monthly Budget Tracking
* 📤 Export Expenses to CSV
* ⚙️ Profile Management
* 🔑 Change Password
* 🌙 Dark Mode
* 📱 Responsive Design
* 🔔 Toast Notifications
* 🚨 Custom Error Pages (404 & 500)

## 🛠️ Tech Stack

### Backend

* Flask
* SQLite
* Gunicorn

### Frontend

* HTML5
* CSS3
* JavaScript

### Charts

* Chart.js

### Deployment

* Render

## 🚀 Installation

```bash
git clone https://github.com/apurva616/ExpenseTrackerPro.git

cd ExpenseTrackerPro

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python backend/app.py
```
